## Task 1: Private 30-line spot check against trigpointing.uk logs (#12)

Goal: estimate how often the model's per-line verdicts agree with what visitors to the pillars report.

- Inputs: visible lines in `data/gb_lines.csv` + `data/gb_lines_long.csv` (columns
  `a,b,a_name,b_name,dist_km,clearance_m,a_e,a_n,b_e,b_n`), the surface flag in `data/gb_surface.csv`
  (`a,b,clear_glo30`; clear when > 0), pillar heights from `site/data/pillars.json` rows
  `[id, name, lon, lat, height_m, n, s]` (ids are OS station names with "/" replaced by "-").
- First, read trigpointing.uk's terms of use. If they forbid automated access, stop and report BLOCKED. robots.txt
  allows all agents. Prefer the public API (`https://api.trigpointing.uk/v1/...`) over HTML pages if it exposes
  logs. Rate limit: at most 1 request per second, at most 600 requests in total, identifying User-Agent
  "retriangulation-redrawn spot check (private research)". Cache every response under `data/spotcheck/` so a
  rerun makes no requests.
- Sample: 30 visible lines, stratified 8 / 8 / 7 / 7 across
  (upland, surface-clear), (upland, surface-blocked), (lowland, surface-clear), (lowland, surface-blocked).
  Upland: both pillars ≥ 300 m. Lowland: both pillars ≤ 100 m. Draw with a fixed seed. Within each stratum, prefer
  pairs where both pillars have at least 10 logs, so that evidence is likely; record how the pool was filtered.
- Evidence per line: search each pillar's logs for the other pillar's name (case-insensitive; also the name with
  common suffixes such as "Hill", "Beacon" or "Farm" removed when distinctive). Classify each mention by hand-written
  rules on the surrounding sentence: SEEN (e.g. "could see", "visible", "in view"), NOT_SEEN (e.g. "couldn't see",
  "hidden", "blocked by trees"), or AMBIGUOUS. A line with no mention is NO_EVIDENCE.
- Outputs:
  - `scripts/spot_check.py` (committed): `fetch` and `run` steps.
  - `data/spotcheck/` (gitignored): raw responses and a per-line evidence file with excerpts.
  - `results/spot_check.json` (committed): counts only — per stratum: lines, SEEN, NOT_SEEN, AMBIGUOUS, NO_EVIDENCE,
    and agreement (model surface flag vs SEEN/NOT_SEEN) — plus sampling parameters, seed and request count.
    No log text, usernames or log URLs.
- Verification: the run step works offline from the cache (rerun after `fetch` makes 0 requests), the counts in the
  JSON add up to 30, and 5 lines with evidence are checked by hand against their cached excerpts (note which in the
  report file, not in results/).

  `wrangler pages deploy` to a project named `retriangulation-redrawn`.
- Turn on Cloudflare Web Analytics for the Pages project.
- Verification: the pages.dev URL loads with tiles streaming from R2, no console errors, and
  `scripts/measure_payload.py <url>` saved as `results/payload_preview.json`. Analytics records a visit.
